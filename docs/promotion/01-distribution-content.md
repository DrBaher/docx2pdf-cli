# 01 — Distribution Content Pack

Use this copy verbatim in docs, release notes, package pages, and agent registries.

## One-liner

`docx2pdf-cli` is an honest, batch-aware DOCX→PDF CLI for humans and agents.

## Short pitch (2 lines)

Convert `.docx` to `.pdf` with transparent backend selection (`--why`), strict fidelity protection (`--strict-fidelity`), and automation-friendly JSON/NDJSON output.

## Install snippets

```bash
npm i -g docx2pdf-cli
docx2pdf --doctor
```

## Agent default snippet

```bash
docx2pdf --strict-fidelity --json --out-dir ./pdfs *.docx
```

## 5 key bullets

- **Transparent backend decisions** via `--why`
- **No silent quality downgrade** with `--strict-fidelity`
- **Batch + NDJSON** for CI and autonomous agents
- **Concurrency-safe LibreOffice** for parallel runs
- **Hybrid backends** across local/server/cloud/macOS automation
